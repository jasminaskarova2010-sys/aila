# Как загрузить Айлу на GitHub

Проект уже подготовлен: ключи и пароли из него убраны, лишнее закрыто файлом `.gitignore`.
Осталось завести аккаунт, войти и загрузить проект.

## Шаг 1. Аккаунт (делаете вы)

1. Откройте https://github.com/signup и создайте аккаунт. Пароль придумываете и храните только вы, Claude его не вводит.
2. Включите двухфакторную защиту: Settings → Password and authentication → Two-factor authentication.
3. Скрытая почта для коммитов (по желанию):
   - откройте Settings → Emails и включите «Keep my email addresses private»;
   - скопируйте адрес вида `12345678+имя@users.noreply.github.com` и пришлите его Claude.

## Шаг 2. Вход с этого Mac (вместе)

1. Claude запускает команду:

   ```bash
   gh auth login --web --git-protocol https
   ```

2. Команда показывает код из 8 символов, например `ABCD-1234`.
3. Вы открываете https://github.com/login/device, вводите код и нажимаете «Authorize».
4. Claude проверяет вход командой `gh auth status`.

## Шаг 3. Загрузка (делает Claude)

```bash
gh repo create aila --private --source . --remote origin --push
```

- `--private`: репозиторий закрытый, его видите только вы и те, кого вы пригласите.
- Проект весит около 80 МБ, загрузка может занять несколько минут.

## Шаг 4. Проверка

1. Откройте `https://github.com/<ваше имя>/aila`: там должны быть все папки и README.
2. На вкладке «Actions» запустится «Проверка»: GitHub сам проверит код и прогонит тесты. Зелёная галочка значит, что всё в порядке.

## Перед тем как сделать репозиторий открытым

Сейчас репозиторий закрытый. Если когда-нибудь захотите открыть его всем:

- уберите личные телефоны и почту из `lib/support_screen.dart`, они будут видны всем;
- выберите лицензию на код (файл `LICENSE`);
- помните, что картинки ARASAAC разрешены только для бесплатного приложения.
