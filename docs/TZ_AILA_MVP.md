## 1. О продукте

**Айла** — Flutter-приложение для детей с РАС и задержкой речи и их родителей. Языки: русский, казахский, английский.

**Цель MVP:** рабочая версия, которую можно дать на проверку 2–3 специалистам (логопед, дефектолог, ABA-терапист) и 5–10 семьям.

**Ядро MVP** — доска общения на картинках, основанная на поэтапном подходе обмена картинками (фазы III–VI). Вокруг неё:
- опрос родителя для выбора стартового уровня;
- 2–3 игры на тех же карточках;
- речевая практика вместе с родителем;
- родительский раздел.

**Целевые дети:** те, кто уже умеет сам отдать карточку взрослому, чтобы что-то получить (фазы I–II освоены). Фазы I–II требуют живого обмена карточкой между людьми и в приложении не тренируются. Таким семьям приложение честно советует начать со специалистом.

**Позиционирование:** образовательное средство, а не медицинское изделие. Никаких обещаний лечения, диагноза или «одобрено врачами».

### Что НЕ входит в MVP

- Регистрация, вход по email, сервер, облако, синхронизация между устройствами.
- Распознавание речи микрофоном.
- Подписки, покупки, реклама, аналитика (Firebase Analytics и подобное).
- Тренировка фаз I–II.

## 2. Обязательные принципы (действуют на всех этапах)

| # | Принцип | Что это значит в коде |
| --- | --- | --- |
| П1 | Ребёнок начинает общение сам | Никаких голосовых или мигающих подсказок «нажми сюда», никаких таймеров, которые торопят |
| П2 | На каждое сообщение отвечает взрослый | После озвучки фразы появляется крупная подсказка для взрослого на 2–3 секунды |
| П3 | Речь поощряется, но не требуется | Ничего не блокируется, если ребёнок молчит |
| П4 | Предсказуемость | Карточки не меняют место сами. Никаких случайных перестановок на доске |
| П5 | Спокойная обратная связь | Никакого красного цвета и звуков «неправильно». На доске не бывает ошибок |
| П6 | Безопасность ребёнка | Настройки, покупки, ссылки и журнал доступны только за PIN родителя |
| П7 | Приватность | Все данные хранятся только на устройстве. Ничего не отправляется в сеть |
| П8 | Работа без интернета | Картинки, озвучка и контент хранятся локально |
| П9 | Торговая марка | Слово «PECS» не используется в интерфейсе. Пишем «Доска общения», «Карточки» |
| П10 | Без emoji | Ни в учебном контенте, ни на карточках (правило уже есть в CLAUDE.md) |
| П11 | Карточки — по лицензии | Пробная версия бесплатная, поэтому основной набор — пиктограммы ARASAAC (CC BY-NC-SA, только некоммерческое использование). В приложении нет платы, подписок, покупок и рекламы. Атрибуция ARASAAC обязательна. Набор картинок подключается через один слой, чтобы при переходе на платную версию его можно было заменить без переделки экранов |
| П12 | Тихий визуальный стиль | Пастельная палитра, скруглённые формы, без мигания. Этот стиль уже в проекте, сохраняем его |

### Этап 1. Честная основа

Исправляем проблемы, которые нашёл предыдущий обзор кода.

**Задачи:**
1. **Сохранение прогресса.** `AppState` сейчас живёт только в памяти. Сохраняй состояние на устройстве (shared_preferences или Hive — выбери и объясни), загружай при запуске, сохраняй при каждом изменении. Сохраняются: профиль ребёнка, звёзды, купленные наряды, пройденные задания, настройки.
2. **Убрать фальшивый вход.** Удали экраны или поля email/пароль. Вместо них:
   - **Экран «Профиль ребёнка»** при первом запуске: имя (необязательно), возраст, язык (ru / kk / en). Можно создать несколько профилей.
   - **PIN родителя** (4 цифры), который задаётся при первом запуске. Он защищает настройки, родительский раздел и любые внешние ссылки. Если PIN забыт, его можно сбросить ответом на простой пример (например, 23 × 4) — защита от ребёнка, а не от взрослого.
3. **Честные звёзды.** Звёзды начисляются только за первое прохождение задания. Повторное прохождение разрешено, но звёзд не даёт.
4. **Честная речевая игра.** В `speak_game_screen.dart` убери автоматический «успех» через 1,6 секунды. Новый сценарий: приложение произносит слово → ребёнок пробует повторить → **родитель** нажимает «Получилось» или «Попробуем потом». Оба варианта нейтральны: «Попробуем потом» не показывает ошибку (П5). Подпиши игру «Тренировка вместе с родителем».

**Готово, когда:**
- [ ] Закрыла приложение полностью, открыла снова — профиль, звёзды и наряды на месте.
- [ ] Нигде нет полей email/пароль.
- [ ] В настройки нельзя попасть без PIN.
- [ ] Повторное прохождение задания не добавляет звёзд.
- [ ] Речевая игра не засчитывает успех сама.

### Этап 2. Доска общения

Главный этап. Сейчас доска — сетка карточек с озвучкой, родителям непонятно, как ею пользоваться. Нужна доска, которая растёт вместе с ребёнком по фазам.

#### 2.1. Устройство экрана (сверху вниз)

1. **Полоска предложения.** Горизонтальная полоса, куда попадают выбранные карточки. Справа две кнопки:
   - «Сказать» — озвучить всю фразу (нажатие на саму полоску тоже озвучивает её);
   - «Стереть» — удалить последнюю карточку, долгое нажатие очищает всё.
2. **Строка стартовых фраз** (видна с фазы IV): «Я хочу», «Я вижу», «Я слышу», «Я чувствую», «Это». Стартовая фраза всегда встаёт первой в полоске.
3. **Закреплённая строка** (видна всегда, на любой фазе): «туалет», «больно», «помоги», «стоп», «перерыв».
4. **Сетка карточек** текущей категории.
5. **Нижняя панель категорий:** Еда, Напитки, Игрушки, Действия, Люди, Места, Чувства, Описания. Кнопка «Домой» ведёт на главную страницу доски.

#### 2.2. Поведение карточки

- **Нажатие:** карточка плавно увеличивается на 150–200 мс (без мигания), её слово озвучивается, карточка добавляется в полоску.
- **Подпись:** под картинкой, крупным шрифтом, на языке профиля.
- **Цвет рамки по категории** (мягкие пастельные тона, вынести в одну тему):

  | Тип слова | Цвет |
  | --- | --- |
  | люди | жёлтый |
  | действия | зелёный |
  | предметы | оранжевый |
  | описания | голубой |
  | социальные фразы | розовый |
  | вопросы | фиолетовый |

- **Размер:** зависит от количества карточек на экране (2 карточки — очень крупные), но не меньше 72×72 dp.

#### 2.3. Подсказка взрослому (П2)

После «Сказать» (или после нажатия на карточку в фазе III) вверху на 2–3 секунды появляется крупная плашка для взрослого:
- в режиме просьбы: «Ребёнок просит: яблоко. Дайте и назовите вслух»;
- в режиме комментария: «Ребёнок говорит: я вижу птицу. Ответьте ему».

Плашку можно отключить в настройках родителя.

#### 2.4. Режимы по фазам

Фаза хранится в профиле ребёнка. Родитель меняет её в настройках (за PIN).

| Фаза | Что видит ребёнок | Логика |
| --- | --- | --- |
| III-A | 2 крупные карточки: любимый предмет и нейтральный | Родитель выбирает любимые предметы из списка. Полоски предложения нет: нажатие сразу озвучивает слово и показывает подсказку взрослому |
| III-B | От 3 до 6 карточек, потом категории | Количество карточек задаёт родитель (слайдер 3–20). Категории открываются переключателем |
| IV | Полоска предложения, «Я хочу» уже стоит первой | Ребёнок добавляет предмет и нажимает «Сказать» |
| IV+ | Открывается категория «Описания» | Можно собрать «Я хочу большой красный мяч». Порядок слов в озвучке грамматически правильный для языка |
| V | Кнопка «Задать вопрос» у родителя | Родитель нажимает → звучит «Что ты хочешь?» → ребёнок отвечает фразой. Обычные спонтанные просьбы продолжают работать |
| VI | Стартовые фразы «Я вижу», «Я слышу», «Это» + карточки окружающих предметов | Режим «Что ты видишь?» работает как вопрос в фазе V |

Заметка про русский и казахский: «Я хочу большой красный мяч» в русском требует согласования по роду и падежу. В MVP достаточно хранить у карточки описания готовые формы для частых сочетаний или озвучивать слова по отдельности с короткой паузой. Выбери вариант, объясни его и не усложняй.

#### 2.5. Стартовый набор слов

Ровно 60 карточек (остальные родитель добавляет сам). Картинки — пиктограммы ARASAAC.

**Как подключить ARASAAC:**
1. Проверь формат запросов в официальной документации API ARASAAC (раздел для разработчиков на arasaac.org; основной адрес API — `https://api.arasaac.org`). Не угадывай адреса.
2. Напиши скрипт `tool/fetch_arasaac.dart` (или на Python в `tool/`). Для каждого слова из списка ниже он ищет пиктограмму по русскому ключевому слову (если не найдено — по английскому) и берёт первый результат.
3. **Перед скачиванием всех картинок** покажи мне таблицу «слово → id ARASAAC → ссылка на картинку» для первых 5 слов. Жди подтверждения.
4. Скачай PNG (300–500 px) в `assets/pictograms/arasaac/` с понятными именами (`apple.png`, `mom.png`). Создай `assets/pictograms/arasaac/manifest.json` (слово → id → файл) и `assets/pictograms/arasaac/LICENSE.md` с текстом атрибуции.
5. Выведи в отчёте полную таблицу «слово → id → файл», чтобы владелица просмотрела картинки и отметила неудачные. Неудачные заменяются правкой `manifest.json` и повторным запуском скрипта.
6. Картинки лежат в приложении. Приложение **не** обращается к ARASAAC во время работы (П8).

**Слой набора картинок:** создай один класс (например, `PictogramRepository`), который по id слова возвращает картинку. Экраны не знают, откуда картинка. Текущие Mulberry Symbols из `assets/pecs_symbols/` не удаляй: оставь их вторым набором, который включается одной настройкой в коде. Это понадобится, если приложение станет платным.

Если для слова в ARASAAC нет подходящей пиктограммы, используй Mulberry или простую однозначную векторную пиктограмму и отметь это в `manifest.json`.

**Атрибуция ARASAAC** (на экране «О приложении» и в `LICENSE.md`): «Автор пиктограмм: Sergio Palao. Источник: ARASAAC (https://arasaac.org). Лицензия: CC BY-NC-SA. Собственность: Правительство Арагона».

- **Стартовые фразы:** Я хочу, Я вижу, Я слышу, Я чувствую, Это.
- **Социальные:** да, нет, помоги, ещё, всё (закончил), стоп, перерыв, привет, пока, спасибо.
- **Еда и напитки:** вода, сок, молоко, яблоко, банан, печенье, хлеб, каша, мороженое.
- **Игрушки и занятия:** мяч, машинка, кубики, мыльные пузыри, книга, мультик, рисовать, музыка.
- **Действия:** есть, пить, играть, идти, спать, мыть руки, туалет, открыть.
- **Люди:** мама, папа, бабушка, дедушка, брат, сестра, я.
- **Чувства:** хорошо, плохо, больно, устал, грустно, злюсь, страшно.
- **Описания:** большой, маленький, красный, синий, жёлтый, зелёный.

#### 2.6. Карточки родителя

В родительском разделе (за PIN):
- **Добавить карточку:** фото с камеры или из галереи + подпись + запись голоса родителя (необязательно). Запись голоса важнее синтеза речи.
- **Скрыть или показать** карточку или категорию. Не удалять: ребёнок привыкает к расположению.
- **Список «Любимые предметы»** для фазы III-A.

#### 2.7. Озвучка и язык

- Все тексты карточек и интерфейса — через систему локализации проекта (класс `S`). Никакого хардкода на русском.
- TTS на языке профиля: убери жёсткий `setLanguage('ru-RU')`.
- Если на устройстве нет голоса для казахского, покажи родителю понятное сообщение и предложи записать свой голос для карточек.

#### 2.8. Чего не делать

- Не начислять звёзды за использование доски: общение — не игра на награды.
- Не показывать рекламу, ссылки и покупки на экранах ребёнка.

**Готово, когда:**
- [ ] В фазе III-A на экране две крупные карточки; нажатие озвучивает слово и показывает подсказку взрослому.
- [ ] В фазе IV фраза «Я хочу яблоко» собирается и озвучивается за 2 нажатия.
- [ ] В фазе IV+ собирается «Я хочу большой красный мяч», озвучка звучит понятно.
- [ ] В фазе V работает «Задать вопрос», в фазе VI — «Что ты видишь?».
- [ ] Закреплённая строка (туалет, больно, помоги, стоп, перерыв) видна на всех фазах.
- [ ] Родитель добавил карточку с фото и своим голосом, перезапустил приложение — карточка на месте.
- [ ] Переключение языка меняет и подписи, и озвучку.
- [ ] Все 60 стартовых карточек показаны пиктограммами ARASAAC (кроме отмеченных в `manifest.json`), в режиме полёта картинки на месте.
- [ ] Одна настройка в коде переключает доску на Mulberry Symbols, и экраны при этом не ломаются.

### Этап 3. Опрос родителя и выбор фазы

**Задачи:**
1. **Онбординг-опрос** после создания профиля, 8 вопросов. Варианты ответа на каждый: «Никогда», «Иногда», «Почти всегда». Вопросы о наблюдаемом поведении, без медицинских терминов.

   | # | Вопрос | Фаза |
   | --- | --- | --- |
   | 1 | Ребёнок сам даёт вам картинку или предмет, чтобы получить то, что хочет? | I |
   | 2 | Ребёнок сам подходит к вам или к своим карточкам, даже если вы в другом конце комнаты? | II |
   | 3 | Если перед ребёнком две картинки, он выбирает ту, что изображает нужную вещь? | III-A |
   | 4 | Ребёнок находит нужную картинку среди 5 и больше или на другой странице? | III-B |
   | 5 | Ребёнок составляет из двух картинок фразу «Я хочу + предмет»? | IV |
   | 6 | Ребёнок добавляет к просьбе цвет, размер или действие («большой мяч»)? | IV+ |
   | 7 | Ребёнок отвечает картинками или словами на вопрос «Что ты хочешь?» | V |
   | 8 | Ребёнок сам рассказывает о том, что видит или слышит («я вижу собаку»)? | VI |

2. **Расчёт стартовой фазы:**
   - Если на вопрос 1 или 2 ответ не «Почти всегда», показать экран: «Сейчас ребёнку важнее научиться отдавать карточку взрослому из рук в руки. Это лучше делать с напечатанными карточками и специалистом». На экране кнопка «Распечатать набор карточек» (PDF, этап 3, задача 4) и кнопка «Всё равно открыть доску» (стартует с фазы III-A).
   - Иначе стартовая фаза — первая из вопросов 3–8, где ответ не «Почти всегда». Если везде «Почти всегда» — фаза VI.
   - На экране результата: рекомендованная фаза + одна фраза, чему ребёнок будет учиться. Кнопка «Изменить фазу вручную».
3. **Подпись под опросом:** «Это не диагноз и не медицинская оценка. Опрос помогает выбрать, с чего начать. Если сомневаетесь, обратитесь к логопеду или дефектологу». Вопросы оформи как черновик: в коде отметь, что их должен проверить специалист.
4. **PDF с 12 базовыми карточками** для печати (крупно, с подписями на языке профиля): вода, есть, туалет, помоги, мама, папа, мяч, книга, ещё, всё, да, нет.
5. **Совет на сегодня** в родительском разделе: 3–4 строки о том, как заниматься на текущей фазе. Пример для фазы IV: «Оставьте любимую вещь на виду, но вне досягаемости. Ждите, пока ребёнок сам соберёт фразу. Не говорите “скажи”, просто ответьте на фразу».
6. **Повторный опрос:** через 4 недели после последнего прохождения в родительском разделе появляется ненавязчивое напоминание «Пройти опрос заново?».

**Готово, когда:**
- [ ] Ответ «Никогда» на вопрос 1 ведёт на экран «начните со специалистом» с кнопкой PDF.
- [ ] Ответы «Почти всегда» на 1–4 и «Иногда» на 5 дают фазу IV.
- [ ] PDF открывается и печатается, подписи на языке профиля.
- [ ] Фазу можно сменить вручную, и доска сразу меняется.

---

### Этап 4. Игры, паузы и языки

**Задачи:**
1. **Игры на карточках ребёнка.** Перестрой игры (`kGameSteps` и связанные экраны), чтобы они брали слова из словаря доски, а не из отдельного списка. Минимум две игры:
   - «Найди картинку» — выбор из 2–6 карточек, число зависит от фазы;
   - «Собери фразу» — для фаз IV и выше.
2. **Сессии и перерывы.** После 3–5 заданий (настройка родителя) — спокойный экран «Время перерыва» с карточкой «перерыв» и кнопкой «Продолжить» для родителя.
3. **Локализация контента.** Тексты заданий, социальные истории и озвучка игр — на языке профиля через `S`.
4. **Журнал для пилота** (только на устройстве, П7). Записываются: время; сказанная фраза; число карточек во фразе; была ли фраза ответом на вопрос (фазы V–VI) или спонтанной; смена фазы. В родительском разделе:
   - экран «Сегодня»: число спонтанных фраз и фраз из 2+ карточек за день и за неделю;
   - кнопка «Поделиться отчётом» — CSV через системное меню «Поделиться». Родитель сам решает, кому отправить.

**Готово, когда:**
- [ ] Карточка, скрытая родителем на доске, не появляется в играх.
- [ ] После заданного числа заданий появляется экран перерыва.
- [ ] Переключение на казахский меняет тексты игр, озвучку и интерфейс (или выводится честное сообщение про отсутствие голоса).
- [ ] Экран «Сегодня» показывает реальные числа после использования доски.
- [ ] CSV-отчёт создаётся и открывается в таблице.

### Этап 5. Аудит и тестовая сборка

**Задачи:**
1. Запусти `/aac-expert проведи полный аудит приложения`. Если скилла нет, проверь приложение по таблице принципов П1–П12 и по всем пунктам «Готово, когда» и составь отчёт в том же формате: «Критично / Важно / Улучшения / Что уточнить у специалиста».
2. Исправь всё из раздела «Критично». Раздел «Важно» покажи владелице и спроси, что исправлять.
3. **Экран «О приложении»:**
   - назначение;
   - «Не заменяет занятий со специалистом»;
   - атрибуция ARASAAC (текст из этапа 2, раздел 2.5) и Mulberry Symbols, если они используются;
   - простая политика конфиденциальности: «Все данные хранятся только на этом устройстве и никуда не передаются».
4. Подготовь тестовую сборку:
   - Android: `flutter build apk --release` (или appbundle для внутреннего тестирования Google Play);
   - iOS: объясни владелице по шагам, что нужно для TestFlight (аккаунт Apple Developer).
5. Создай `docs/PILOT_GUIDE.md` — инструкцию для семей и специалистов на русском, не больше двух страниц. Содержание: как начать, как проходить опрос, что делать на каждой фазе, как отправить отчёт.

**Готово, когда:**
- [ ] В отчёте аудита нет пунктов «Критично».
- [ ] Есть рабочая сборка, которую можно установить на телефон.
- [ ] Есть экран «О приложении» и `docs/PILOT_GUIDE.md`.

## 4. Финальная проверка перед пилотом

Проверяет владелица, лучше вместе со специалистом:

- [ ] Человек, который видит приложение впервые, за 2 минуты собирает и озвучивает «Я хочу яблоко».
- [ ] Нет мигания, резких звуков, красных «ошибок».
- [ ] Ребёнок не может попасть в настройки без PIN.
- [ ] Приложение работает в режиме полёта.
- [ ] Нигде в интерфейсе нет слова «PECS» и обещаний лечения.
- [ ] Специалист посмотрел вопросы опроса и советы по фазам.
